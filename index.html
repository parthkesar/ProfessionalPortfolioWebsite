Rogue Energy E-commerce Website

Rogue Energy — Full-Stack E-Commerce Web Application

Rogue Energy is a modern, visually engaging full-stack e-commerce web application designed for an energy drink brand. The project combines a dynamic and responsive frontend with a Python Flask backend and MySQL database to create an interactive shopping experience. It demonstrates practical implementation of frontend development, backend programming, database integration, API communication, responsive design, and modern web interactions.

Project Overview

The website is designed around a bold, high-energy visual identity with cinematic background videos, smooth animations, interactive product cards, responsive layouts, and an intuitive shopping experience. Users can explore the brand, browse available products, add products to their shopping cart, review their order, provide checkout information, and submit inquiries through the contact section.

The project follows a client-server architecture where the frontend communicates with the Flask backend through HTTP requests and JSON-based API endpoints, while MySQL is used for persistent storage of customer messages and orders.

Key Features

  • Modern Landing Page: A visually rich homepage featuring a cinematic video hero section, strong typography, branded visuals, call-to-action elements, and smooth transitions.
  • Responsive Design: The interface is designed to adapt across desktop, tablet, and mobile screen sizes using responsive CSS layouts and media queries.
  • Interactive Product Section: Products are presented through visually appealing product cards with pricing information, hover effects, and interactive Add to Cart functionality.
  • Shopping Cart: A dynamic JavaScript-powered shopping cart allows users to add products, manage quantities, view selected items, calculate the order total, and clear their cart.
  • Persistent Cart Storage: The shopping cart uses browser localStorage, allowing cart information to remain available even when the page is refreshed.
  • Checkout System: A dedicated checkout interface collects customer and delivery information and sends the order data to the Flask backend for processing.
  • Database Integration: MySQL is integrated with the Flask backend to store customer contact messages and order information securely and persistently.
  • AJAX-Based Communication: JavaScript's fetch() API is used to communicate with Flask endpoints without requiring unnecessary page reloads, creating a smoother application experience.
  • Contact Form: An interactive contact form allows visitors to submit their name, email address, and message, which are processed by Flask and stored in the database.
  • Interactive UI Elements: The project includes modal windows, toast notifications, animated buttons, hover effects, mobile navigation, smooth scrolling, and dynamic UI updates.
  • Video-Based Branding: HTML5 video is used to create an immersive hero section that strengthens the visual identity of the Rogue Energy brand.
  • Accessibility Considerations: The interface incorporates semantic HTML elements, ARIA attributes, accessible labels, dialog semantics, live announcements, and a skip-navigation link.
  • SEO-Friendly Structure: The website includes metadata, descriptive information, canonical URL configuration, Open Graph metadata, and social sharing metadata.

Technology Stack

Python Flask MySQL HTML5 CSS3 JavaScript Jinja2 REST APIs Fetch API LocalStorage Responsive Design

Frontend Development

The frontend is built using HTML5, CSS3, and JavaScript. HTML provides the semantic structure of the application, CSS creates the visual design and responsive layouts, and JavaScript provides the interactive functionality.

The interface uses modern CSS techniques including transitions, transformations, animations, flexbox-based layouts, responsive media queries, hover interactions, and modal-based components to create a polished user experience.

Backend Development

The backend is powered by Python Flask. Flask manages application routing, template rendering, HTTP requests, JSON responses, form processing, and communication with the MySQL database.

The application provides dedicated backend endpoints for handling contact submissions, shopping cart operations, and checkout requests. This creates a clear communication layer between the frontend interface and the database.

Database Integration

MySQL is used as the application's relational database. The Flask backend establishes database connections using MySQL Connector/Python and processes customer and order information through SQL queries.

This integration demonstrates how a Python web application can communicate with a relational database to persist information beyond the user's browser session.

Shopping Experience

The shopping functionality creates a complete interactive flow from product discovery to order submission. Users can select products, add them to their cart, adjust quantities, view the calculated total, and continue to checkout.

JavaScript manages the cart dynamically while localStorage provides persistent browser-side storage. During checkout, the frontend communicates with Flask through a JSON API, allowing the backend to process and store the order information.

Professional Portfolio Website

Personal Portfolio Website — Full-Stack Developer Portfolio

Personal Portfolio Website is a modern, responsive, and interactive developer portfolio designed to showcase professional skills, technical expertise, projects, and development capabilities. The website presents a clean dark-themed interface with gradient visual elements, responsive layouts, interactive navigation, animated content, skill cards, project showcases, and an integrated contact system.

The project demonstrates practical frontend development skills using HTML5, CSS3, and JavaScript, while also integrating with a hosted backend API for processing contact form submissions. Particular attention has been given to responsive design, user interaction, accessibility, SEO, performance considerations, and creating a professional developer-focused visual identity.

Project Overview

The portfolio is structured as a single-page website containing dedicated sections for About Me, Skills, Projects, and Contact. Visitors can navigate smoothly between sections, explore technical skills, expand project information, and send messages through the contact form.

The interface follows a dark, technology-oriented visual style using cyan and blue gradient accents, animated interactions, responsive layouts, and card-based components. The design adapts across desktop, tablet, and mobile devices to provide a consistent experience on different screen sizes.

Key Features

  • Modern Developer Portfolio: A professional single-page portfolio designed to present personal information, development skills, projects, and contact details in a structured and visually engaging format.
  • Interactive Typewriter Effect: JavaScript dynamically cycles through professional roles such as Full-Stack Developer, Software Developer, and Mobile App Developer using a typewriter and deletion animation.
  • Smooth Section Navigation: Navigation items use JavaScript-powered smooth scrolling to move between the About, Skills, Projects, and Contact sections without traditional page navigation.
  • Dynamic Navigation Highlight: The navigation includes a gradient highlight indicator that dynamically moves beneath the selected navigation item.
  • Responsive Navigation Menu: A mobile hamburger menu is implemented using JavaScript and CSS, allowing navigation links to transform into a compact mobile-friendly menu on smaller screens.
  • Responsive About Section: The About section uses a flexible two-column layout on larger screens and automatically changes to a vertically stacked layout on smaller devices.
  • Interactive Skill Cards: Technical skills are presented through visually styled cards containing technology icons, skill names, and experience indicators.
  • Skill Showcase: The portfolio highlights technologies and development areas including HTML/CSS/JavaScript, React.js, React Native, MERN Stack, Electron.js, Python, Flask, MySQL, and REST APIs.
  • Project Showcase: Projects are presented using expandable project containers, allowing visitors to reveal detailed project descriptions without leaving the portfolio page.
  • Expandable Project Details: JavaScript dynamically controls project-description containers and adjusts their height to create smooth open-and-close animations.
  • Responsive Project Layout: Project containers, headings, images, descriptions, and navigation controls adapt their sizing and spacing according to the device viewport.
  • Integrated Contact System: A dedicated contact section allows visitors to provide their name, phone number, email address, and message.
  • API-Based Contact Form: The contact form uses the JavaScript fetch() API to send submitted information as JSON to a hosted backend endpoint.
  • Asynchronous Form Submission: Contact information is submitted without reloading the portfolio page, providing a smoother user experience.
  • Submission State Management: During form submission, the submit button is disabled and its text changes to indicate that the message is being processed.
  • Success Feedback: After a successful submission, the interface displays a dedicated thank-you message and temporarily hides the form controls.
  • Error Handling: The JavaScript implementation handles unsuccessful HTTP responses, connection failures, and unexpected errors while restoring the form to its usable state.
  • Interactive Visual Design: Gradient borders, hover effects, card elevation, transitions, animated controls, and smooth UI interactions create a modern developer-portfolio aesthetic.
  • Accessibility Considerations: The project incorporates semantic elements, descriptive image alt attributes, ARIA labels, navigation menu state management, accessible button labels, and keyboard-friendly focus states.
  • Reduced Motion Support: A prefers-reduced-motion media query is included to reduce animations and transitions for users who prefer reduced motion.
  • Print-Friendly Design: Dedicated print styles remove unnecessary navigation and social elements and optimize the website for printed output.
  • SEO Optimization: The website includes descriptive metadata, keywords, Open Graph metadata, Twitter Card metadata, canonical-style URL information, and structured data.
  • Structured Data: Schema.org JSON-LD structured data is included to describe the portfolio owner, professional role, website, and contact information to search engines.
  • Search Engine Configuration: A robots.txt file and XML sitemap are included to provide search engine crawling and indexing information.

Frontend Development

The frontend is developed using HTML5, CSS3, and vanilla JavaScript. HTML provides the semantic structure of the portfolio, CSS handles the visual presentation and responsive layouts, and JavaScript controls dynamic behavior and user interactions.

The website uses modern CSS techniques including Flexbox, responsive media queries, gradients, transitions, transformations, animations, shadows, responsive typography, and component-oriented styling to create a polished interface.

The project intentionally uses lightweight frontend technologies without depending on a large JavaScript framework, allowing the portfolio to remain relatively simple, maintainable, and efficient.

JavaScript Functionality

JavaScript provides the interactive layer of the portfolio. The application dynamically controls the typewriter animation, project expansion, navigation behavior, mobile menu, navigation highlighting, contact form submission, loading states, success feedback, and error handling.

Event listeners are used extensively to respond to user interactions such as navigation clicks, project-bar clicks, hamburger-menu actions, and contact-form submission. The code also includes global error and unhandled promise rejection handlers to assist with debugging and runtime error management.

Contact Form & API Integration

The contact form demonstrates integration between a frontend application and a remote backend service. When a visitor submits the form, JavaScript collects the entered data using the FormData API and constructs a JSON request.

The request is sent asynchronously using the browser's native fetch() API with an HTTP POST request. The backend response is then processed to determine whether the submission was successful or whether an error should be presented to the user.

This architecture keeps the portfolio frontend separate from the server-side contact processing system while providing a smooth client-side experience.

Responsive Design

Responsive behavior is one of the major design aspects of the project. Multiple CSS breakpoints are used to adapt navigation, typography, project containers, skill cards, contact forms, spacing, and content layouts for different viewport sizes.

On desktop screens, content makes use of wider layouts and multi-column arrangements, while smaller screens transition toward stacked layouts and compact navigation. A dedicated hamburger navigation system is provided for mobile devices.

UI & Interaction Design

The visual identity is built around a dark background combined with cyan-to-blue gradients. This creates a consistent technology-focused appearance throughout the portfolio.

Interactive components use CSS transitions and JavaScript-driven state changes to provide visual feedback. Skill cards lift on hover, navigation elements receive animated highlights, project descriptions expand smoothly, buttons provide hover and focus states, and social links respond to user interaction.

SEO & Web Optimization

SEO has been considered at both the document and website-configuration levels. The HTML document contains a descriptive title, meta description, author information, keywords, Open Graph metadata, Twitter Card metadata, and Schema.org structured data.

The project also includes a robots.txt configuration and an XML sitemap containing the major sections of the portfolio, helping search engines understand the website structure.
